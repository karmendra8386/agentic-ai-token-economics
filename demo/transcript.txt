### What this shows
>> Every task returns a receipt: tier, tokens, cost, confidence.
>> Easy tasks stay on cheap tiers; hard ones escalate — the router
>>   total lands far below serving everything on the large tier.
>> Receipts aggregate into cost per correct: spend per SOLVED task,
>>   the number an agent budget should actually be set in.
